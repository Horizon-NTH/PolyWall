## Main capabilities

<div class="polywall-capabilities">
  <ul>
    <li>Image, video, PDF, and presentation library</li>
    <li>Drag-and-drop playlists</li>
    <li>Playlist, static-content, and widget zones</li>
    <li>Clock, weather, RSS, and transit widgets</li>
  </ul>
  <ul>
    <li>Timezone-aware channels and prioritized schedules</li>
    <li>Temporary-code screen pairing</li>
    <li>Organization-level access control</li>
    <li>Asynchronous media conversion and object storage</li>
  </ul>
</div>
