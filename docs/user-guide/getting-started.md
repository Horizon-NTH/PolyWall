# Getting started

This walkthrough creates a minimal end-to-end broadcast.

1. Sign in with an organization administrator or manager account.
2. Open **Médias**, import an image or short video, and wait for the **Prêt** status.
3. Open **Playlists**, create a playlist, and add the media item.
4. Open **Modèles d'affichage** and create a full-screen template with a playlist zone.
5. Open **Canaux**, create a channel, select the template, and verify its timezone.
6. Add a default schedule that connects the playlist to the channel.
7. Open `/display` on the target device and submit a temporary pairing code.
8. Approve the pending screen, name it, and assign it to the channel.
