# Glossary

**Channel**
: Independent schedule stream associated with a display template and one or more screens.

**Display runtime**
: Computed snapshot containing the template, active playlist, media, and widgets required by the player.

**Display template**
: Reference resolution, background, and zones that define a channel's layout.

**Media**
: Imported editorial content with an original and optional generated files.

**Media variant**
: File derived from an original, such as a thumbnail or rendered PDF page.

**Organization**
: Logically isolated tenant that owns users and content.

**Playlist**
: Ordered media list forming a playback loop.

**Schedule**
: Association between a playlist, a channel, and a temporal rule.

**Screen**
: Paired browser device assigned to a channel.

**Widget**
: Dynamic content refreshed independently from playlist playback.
